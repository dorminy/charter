Basics



  This tool creates session-ready Nashville-style charts using either Nashville Numbers (NNS) or chord names.
  Mode is detected automatically based on what you type.




Core Rule



  Each bar represents one full measure (typically 4 beats).




Single chord = full bar unless specified otherwise.



Beat Notation (Dots)



  Beats are defined using dots (·) directly after a chord symbol.





  
InputBeats

  
C4 beats (full bar)

  
C·1 beat

  
C··2 beats

  
C···3 beats






  Dots explicitly define how long a chord lasts.
  More dots = more beats.




Multiple Chords in a Bar



Equal Split (no dots)


C D



  If no dots are provided, the bar splits evenly between all chords.





  
InputMeaning

  
C D2 + 2 beats

  
C D E F1 + 1 + 1 + 1





Explicit Timing (using dots)


C·· D··     → 2 + 2  
C··· D·     → 3 + 1  
C· D···     → 1 + 3  
C· D· E· F· → 1 + 1 + 1 + 1  





  When dots are used, they override the equal split rule.




How It Works


    
  
  • Each bar must match the current time signature
    • 
  
  • No dots → chords divide the bar evenly when possible
    • 
  
  • Dots → explicit duration control
    • 
  
  • Single chord → fills the full bar
    •

Lyric Sheet


    
  
  • Click Lyric Sheet → (top right) to open a separate lyric sheet to accompany the chord chart. ← Chord Chart takes you back.
    • 
  
  • The first time you open it, it copies the chord chart's sections (names and letters). After that it is independent: rename, add, duplicate, move or remove sections without touching the chord chart — for example, add a "Verse 2".
    • 
  
  • Each section has one multi-line box. Type or paste the lyrics, one line per row.
    • 
  
  • Tick No lyrics beside a section (an instrumental, say) to collapse its box so only the section title shows. Untick it to bring the box back — the words are kept.
    • 
  
  • Print Lyric Sheet prints the lyric sheet on its own, scaled to fit the page. If it won't fit on one page it is printed in two columns, filling the left column first.
    • 
  
  • Restart from chord chart clears all lyrics and re-copies the chord chart's current sections.
    • 
  
  • Both sheets are saved together in the one JSON file.
    • 




Hold, Choke & Ties


    
  
  • Click the ◇ chip on a chord to mark it "hold" — a ◇ symbol is shown above the chord, telling the player to let it ring.
    • 
  
  • Click the ▽ chip on a chord to mark it "choke" — a ▽ symbol is shown above the chord, telling the player to cut it off short.
    • 
  
  • To hold a chord longer than one bar: mark the chord ◇ in its own bar, then click the — (tie) chip alone in each following bar it's still held. Each of those bars shows a ◇ with no chord under it — still ringing.
    • 
  
  • Chain — across as many bars as needed — there's no limit.
    • 
  
  • Example: 1◇ then — then — = one chord held for 3 full bars, shown as a chord with a ◇ above it, followed by two bars with just a ◇.
    • 
  
  • Partial-bar ties still work with dots, e.g. —·· 4·· = tied for 2 beats, then a new chord for 2 beats.
    •
